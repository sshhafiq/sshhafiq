Methodology

  • Figures represent the number of applications submitted per interval: hourly for 1D, daily for 1M and 3M, and monthly for 1Y.
  • The moving average is a trailing simple average whose window scales with the number of intervals in the selected range.
  • Period change compares the final interval to the first interval in the selected range.
  • Volatility is the standard deviation of interval values divided by the mean.
  • The selected range is reflected in the page URL, so links can be shared with a specific view.
